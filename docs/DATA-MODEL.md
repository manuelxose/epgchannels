# TDT Platform — data model

Every document below is defined in `apps/backend/src/infrastructure/schema.ts` and
its indexes are created by `apps/backend/src/migrations/runner.ts`. Identifiers are
UUID strings generated by us; MongoDB's `ObjectId` is never used as an identity.

## `channels`

One row per canonical channel. Public identity is `slug`; `_id` never appears in
a public URL.

| Field | Type | Notes |
| --- | --- | --- |
| `_id` | uuid | Internal identity, stable across renames |
| `slug` | string | Public, semantic, unique (`la-1`, `canal-sur`) |
| `name`, `shortName` | string | Display names |
| `country` | string | `ES` or `INT` for international records |
| `region` | `{ code, name }` \| null | ISO 3166-2:ES code without the country prefix |
| `locality` | string \| null | When the emitter is local |
| `languageTag` | string | BCP-47 tag. Stored under this name because MongoDB reserves `language` as a text-index option |
| `category` | enum | Our taxonomy (generalista … otros) |
| `kind` | enum | `linear`, `online`, `eventual`, `guide-only` |
| `websiteUrl` | string \| null | Official emitter page |
| `description` | string | Our editorial text; never copied from a third party |
| `branding` | `{ logoSrc, logoSrcPermission }` \| null | Brand metadata with its display permission |
| `editorialStatus` | enum | `draft`, `review`, `published`, `withdrawn` |
| `timezone` | string | IANA zone used to render the guide |
| `provenance` | array | `{ source, label, url, licence, attribution, digestSha256, capturedAt, editorial }` |
| `aliases` | array | `{ namespace, value }` — `legacy-tdt`, `epg`, `guiatv`, `merged-from` |
| `epg` | `{ sourceId, externalId }` \| null | Guide mapping |
| `mergedInto` | uuid \| null | Set when the record was folded into another |
| `searchText` | string | Folded search forms (accents, articles, glued runs, abbreviations) |
| `reviewedAt`, `createdAt`, `updatedAt` | date | Revision timestamps |
| `revision` | number | Incremented on every write |

Indexes: unique `slug`; `(editorialStatus, category, name)`; `(country, region.code, name)`;
`(languageTag, name)`; text index on `searchText`; `(aliases.namespace, aliases.value)`;
`updatedAt` descending.

## `playback_sources`

One row per integration we know about, licensed or not.

| Field | Type | Notes |
| --- | --- | --- |
| `_id` | uuid | Source identity (returned as `sourceId` in descriptors) |
| `channelId` | uuid | Owning channel |
| `provider` | string | `emitter:<host>`, `platform:<host>` |
| `type` | enum | `hls`, `dash`, `youtube`, `official-embed`, `external` |
| `url` | string \| null | Public media address or official player page |
| `officialPageUrl` | string \| null | Emitter page a human can open |
| `permission` | enum | `emitter-public-stream`, `emitter-embeddable`, `official-player-only`, `open-data-licence`, `explicit-permission`, `unlicensed` |
| `authorisationEvidence` | string \| null | Pointer to the evidence kept outside the repository |
| `conditions` | object | `embedAllowed`, `proxyAllowed`, `worldwide`, `restrictedRegions`, `browserCompatibility`, `requiresForgedHeader`, `emitterAppOnly`, `notes` |
| `priority` | number | Lower wins |
| `editorialStatus` | enum | Only `published` sources can be public |
| `technicalStatus` | enum | `ok`, `unreachable`, `http-error`, `invalid-manifest`, `unknown`, `blocked` |
| `lastVerifiedAt`, `lastVerification` | date, object | Latest verification result and its cause |
| `provenance`, `createdAt`, `updatedAt`, `revision` | | As above |

Indexes: `(channelId, priority)`; `(channelId, editorialStatus)`; `(technicalStatus, lastVerifiedAt)`.

## `programmes`

| Field | Type | Notes |
| --- | --- | --- |
| `_id` | uuid | Programme identity returned by the API |
| `channelId` | uuid | Owning channel |
| `sourceId` | uuid | Guide source that produced it |
| `title`, `description`, `genre`, `coverUrl` | | As published by the guide |
| `start`, `end` | date | Absolute instants (UTC) |
| `externalKey` | string | `${sourceId}|${upstreamChannel}|${upstreamKey}` — the idempotency key |
| `editedAt` | date \| null | Set for editorial programmes |
| `createdAt`, `updatedAt` | date | |

Indexes: unique `(channelId, externalKey)`; `(channelId, start)`; `end`;
`(sourceId, start)`.

## `epg_sources`

| Field | Notes |
| --- | --- |
| `name` | Unique; identifies the source in payloads |
| `kind` | `xmltv`, `json-tdtchannels`, `editorial` |
| `url` | Public feed URL (null for editorial sources) |
| `licence`, `attribution` | Provenance obligations shown with the data |
| `ingestionEnabled` | Whether the scheduled job may fetch it |
| `lastRunAt`, `lastRunStatus`, `lastRunProgrammes` | Result of the last ingestion |

## `audit_log`

| Field | Notes |
| --- | --- |
| `actor` | `{ type: user|system|anonymous, id }` |
| `action` | `channel.create`, `channel.update`, `channel.merge`, `channel.revert`, `source.create`, `source.update`, `source.withdraw`, `source.verify`, `auth.login` … |
| `entityType`, `entityId` | What changed |
| `before`, `after` | Changed fields (channel revisions keep the full audited snapshot) |
| `reason`, `requestId`, `at` | Why, and the correlation id of the request |

Indexes: `(entityType, entityId, at)`; `at`.

## Derived, never stored

`playbackStatus` is computed per request by the publication policy. It is not a
field on the channel: storing it would let a health check and an authorisation
decision drift apart.
